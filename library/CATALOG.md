# ICENI starter library

100 chat + 100 Claude Code workflows. Install a pack with `iceni pack install <name>`.


**100 chat · 100 code · 200 total**


## CHAT packs


### writing-pro (14) — Polish and reshape any piece of writing.
- `proofread` — Proofread this text for grammar, spelling, punctuation and clarity.
- `rewrite-tone` — Rewrite this text in a specified tone (ask which if unclear).
- `summarize` — Summarize this text.
- `expand` — Expand this terse note into full, well-structured prose.
- `simplify` — Rewrite this so a non-expert understands it.
- `headline` — Write 8 headline options for this.
- `hook` — Write 5 opening hooks that make a reader keep going.
- `tighten` — Cut this text by ~40% without losing meaning.
- `paraphrase` — Paraphrase this to avoid repetition while keeping meaning.
- `active-voice` — Convert passive constructions to active voice.
- `bulletize` — Turn this prose into scannable bullet points.
- `title-ideas` — Generate 10 title ideas for this piece.
- `grammar-fix` — Fix only grammar and punctuation, change nothing else.
- `plain-english` — Remove jargon and corporate-speak; say it plainly.

- `magic-numbers` — Find magic numbers/strings that should be named constants.
